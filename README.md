# EDE448 Communication and Behavioral Support Portfolio

This public repository is the dedicated GitHub and Overleaf workspace for Piter Zacari Garcia Bautista's EDE448 **Communication and Positive Behavioral Support Strategies and Resources Portfolio**.

## Overleaf Entry Point

Set `main.tex` as the main document. The project is self-contained:

- `main.tex`: title page, contents, portfolio map, synthesis, and document assembly
- `resources/`: ten numbered practitioner resources
- `assets/artifact-previews/`: public-safe visual artifacts used throughout the portfolio
- `references.bib`: unified bibliography

Overleaf should compile the project with pdfLaTeX and BibTeX. A local equivalent is:

```bash
latexmk -pdf main.tex
```

## Portfolio Structure

The portfolio uses **Communication as Access-to-Agency** as its organizing theme. Its evidence core is the communication system developed during EDU486: a 30-second student video memo after an activity, an every-day personalized science souvenir, a reviewed day-recap evidence story, and a full-week personalized family recap organized per attended day and per activity. The other six resources connect sensory access, inclusive peer culture, Prevent--Teach--Reinforce planning, AAC selection and continuity, and flexible peer participation to that system.

Each resource carries an explicit assignment or practice-artifact trail. Teaching-placement evidence supplies concrete classroom access and instructional context; the Puzzle Plan joins student voice, artifacts, setting, and adult interpretation; EQUITAS asks whose knowledge enters the record, what context is missing, who controls interpretation, and whether communication can change the next lesson, institutional account, or family narrative. Public-native diagrams and redesigned artifact visuals make that evidence-to-agency pathway visible across the collection.

## Public-Safe Evidence Boundary

This repository was intentionally prepared for public access. Portfolio visuals derived from classroom or camp evidence were reviewed and transformed for public use by blurring identifiable faces, removing or replacing identifying details, and using de-identified captions and evidence summaries where appropriate. The public visuals preserve the instructional meaning of the artifacts without presenting the original participant media as unrestricted source material.

Original identifiable photographs or video, family contacts, private correspondence, raw participant records, and other restricted source materials are not published here. Public-safe transformation also does not strengthen an evidence claim: photographs document action and context but do not independently prove understanding; transcripts require source review before exact quotation or speaker identification; and interpretation remains labeled separately from observation.

Several specific evidence boundaries remain important throughout the portfolio. Day 5 has photographs and a same-session clean transcript but no source video. The two full-week recap books and personalized email drafts were completed and reviewed, but no parent-delivery receipt or family response was recovered, so the portfolio describes the packages as prepared for delivery rather than confirmed as received. Prospective AAC examples likewise do not claim that a particular camper used TD Snap or another AAC system.
